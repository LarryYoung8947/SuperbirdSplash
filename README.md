# Superbird

Marketing splash page for the Superbird flying adventure game.

Open `index.html` in a browser, or serve this folder with any static web server.

## Hosting

Hosted with GitHub Pages from the root of the `master` branch. No build step is required.

- Website: https://larryyoung8947.github.io/SuperbirdSplash/
- Privacy policy: https://larryyoung8947.github.io/SuperbirdSplash/privacy.html

Edit `privacy.html` when the game's data practices change. Keep its effective date current and use its direct URL in Google Play Console and the game.
